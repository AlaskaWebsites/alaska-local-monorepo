# 🌐 Documentação de Frontend — Alaska Local (Nuxt 3)

Este diretório contém os guias técnicos e especificações exclusivas da vitrine e experiência do usuário desenvolvida em **Nuxt 3**, **Vue 3** e **Tailwind CSS**.

---

## 📑 Guias Disponíveis

1. **[Design System & 11 Temas Cromáticos](./design-system-e-temas.md)**: Cores, tipografia, paletas temáticas (`food`, `barber`, `health`, `drinks`, `rose`, `amber`, etc.) e acessibilidade.
2. **[Módulo de Agendamentos & Venda Híbrida](./modulo-agendamento-e-servicos.md)**: Lógica do `useBookingSlots`, cálculo de duração cumulativa e despacho no WhatsApp.
3. **[Padrões de Acessibilidade W3C / WCAG](./padroes-de-acessibilidade-e-ux.md)**: Requisitos de semântica ARIA, foco automático, tecla Escape e trava de scroll.
4. **[Categorias Canônicas de Negócio](./categorias-de-negocio.md)**: Modelos visuais e fluxos para *Alaska Menu*, *Alaska Shop*, *Alaska Hub* e *Alaska Pro*.
